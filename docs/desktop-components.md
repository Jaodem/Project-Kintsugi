# Desktop Components

## Introduction

A modern desktop environment is not a single application.

It is a collection of components, each responsible for a specific aspect of the graphical user experience.

Some components are essential for the desktop to function, while others improve usability, convenience, or integration with the operating system.

Understanding these responsibilities is an important step before selecting the software that will implement them.

For Project Kintsugi, components are evaluated according to their architectural role rather than their popularity or default availability.

---

## Core Components

### Compositor

The compositor is the central component of a Wayland desktop.

It coordinates graphical output, user input, and communication between applications and the display.

Without a compositor, a Wayland desktop session cannot exist.

### Desktop Portals

Desktop Portals provide standardized interfaces for applications that need controlled access to desktop features.

They enable integration between applications and the desktop while preserving Wayland's security model.

---

## User Interface Components

### Status Bar

Provides information about the current desktop session, such as workspaces, system status, running applications, and other indicators.

### Application Launcher

Allows users to discover and start installed applications quickly.

Many launchers also provide command execution, file searching, and desktop actions.

### Notification Manager

Displays asynchronous messages generated by applications or system services.

Notifications allow applications to communicate important information without interrupting the user's workflow.

---

## Session Components

### Authentication Agent

Handles requests that require elevated privileges or user authorization.

Rather than granting applications direct access to privileged operations, authentication requests are presented through a trusted desktop component.

### Lock Screen

Protects the active desktop session by requiring user authentication before access is restored.

### Idle Manager

Monitors user inactivity and performs actions such as locking the session, turning off displays, or triggering power-saving behavior.

---

## Appearance Components

### Wallpaper Manager

Controls the desktop background and may also manage wallpapers across multiple monitors.

### Cursor and Theme Integration

Provides a consistent visual appearance for cursors, icons, colors, and graphical themes across desktop applications.

---

## Utility Components

### Clipboard Manager

Extends the standard clipboard by maintaining clipboard history and improving copy-and-paste workflows.

### Screenshot Utility

Captures images of the desktop, individual windows, or selected screen regions.

On Wayland, screenshot tools cooperate with the compositor and desktop portals.

### File Manager

Provides graphical access to the filesystem and integrates with desktop features such as file selection, drag and drop, and removable devices.

### Terminal Emulator

Provides command-line access within the graphical desktop environment and remains one of the primary interfaces for system administration and development.

---

## Project Kintsugi Perspective

This document intentionally describes desktop responsibilities rather than software choices.

Selecting an implementation is a separate engineering decision.

As Project Kintsugi progresses, each major component will be evaluated individually according to the project's guiding principles:

* Understand before modifying.
* Document decisions before implementation.
* Prefer simplicity and maintainability.
* Build the desktop incrementally.

This approach separates architectural understanding from implementation choices, allowing every decision to be documented with clear technical reasoning.
