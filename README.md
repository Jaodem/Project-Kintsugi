# Project Kintsugi

> A personal journey to build a minimalist, reproducible, and fully understood Linux desktop.

## Objective

Project Kintsugi aims to build a Linux desktop where every component has a purpose, every decision is documented, and every configuration is fully understood.

The goal is not to create the most beautiful desktop.

The goal is to create the desktop that best fits the way I work.

## Core Principles

- Every component must justify its existence.
- Every decision must be documented.
- Every configuration must be understood.
- Simplicity over complexity.
- Understanding over copying.
- Evolution over perfection.
